# ТЗ: Фронтенд сайта-портфолио СА

## 1. Цель
Создать интерфейс для демонстрации артефактов системного аналитика.

## 2. Стек
- HTML/CSS/JavaScript
- Axios для HTTP-запросов

## 3. Страницы

### 3.1. Главная страница (/)
- Описание цели сайта
- Описание стека технологий
- Описание вклада как аналитика
- Кнопка "Сменить цвет фона"
- Список артефактов с фильтрами (категория, теги)
- Клик по артефакту → переход на страницу просмотра

### 3.2. Страница артефакта (/artifact/{id})
- Название артефакта
- Категория
- Теги
- Просмотр файла (PDF/MD) или скачивание
- Кнопка "Назад к списку"

### 3.3. Страница регистрации (/register)
- Поля: email, password, first_name, last_name
- Кнопка "Зарегистрироваться"
- Ссылка на страницу входа

### 3.4. Страница входа (/login)
- Поля: email, password
- Кнопка "Войти"
- Ссылка на регистрацию

## 4. Функциональные требования
- При загрузке главной страницы — запрос GET /api/artifacts
- При клике "Сменить цвет" — запрос POST /api/change-color, применение цвета к body
- При регистрации — запрос POST /api/register, редирект на /login
- При входе — запрос POST /api/login, сохранение JWT в localStorage
- Все защищённые запросы — заголовок Authorization: Bearer {token}

## 5. Дизайн
- Минималистичный, чистый
- Цвет фона меняется по кнопке

## 6. Критерии приёмки
- Все страницы работают
- Регистрация и вход работают
- Список артефактов загружается
- Цвет фона меняется и сохраняется
- JWT токен сохраняется и используется
