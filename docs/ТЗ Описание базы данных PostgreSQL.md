# Спецификация структуры данных (БД)

## 1. Таблица `users` (Пользователи)

### Индексы
* `id` — Первичный ключ (Primary Key, PK)


### Структура

| **Атрибут**       | **Описание**                           | **Тип данных** | **Nullable** | **Ограничения / Значение по умолчанию** |
| :---------------- | :------------------------------------- | :------------- | :----------- | :-------------------------------------- |
| **id**            | Уникальный идентификатор пользователя  | UUID           | N            | Primary Key                             |
| **display_name**  | Имя пользователя показываемое на сайте | VARCHAR(64)    | N            | Unique                                  |
| **first_name**    | Имя пользователя                       | VARCHAR(64)    | N            |                                         |
| **last_name**     | Фамилия пользователя                   | VARCHAR(64)    | N            |                                         |
| **patronymic**    | Отчество пользователя                  | VARCHAR(64)    | Y            |                                         |
| **password_hash** | Хэш пароля пользователя                | VARCHAR(255)   | N            |                                         |
| **created_at**    | Дата и время регистрации               | TIMESTAMPTZ    | N            | DEFAULT CURRENT_TIMESTAMPTZ             |


---

## 2. Таблица `user_current_colors` (Текущий цвет пользователя)


### Индексы
* `user_id` — Первичный ключ (PK) и Внешний ключ (FK)

### Структура

| **Атрибут**       | **Описание**                                 | **Тип данных** | **Nullable** | **Ограничения / Значение по умолчанию** |
| :---------------- | :------------------------------------------- | :------------- | :----------- | :-------------------------------------- |
| **user_id**       | Идентификатор пользователя                   | UUID           | N            | PK, FK → `users.id` (ON DELETE CASCADE) |
| **current_color** | Текущий цвет фона (например, "rgb(255,0,0)") | VARCHAR(20)    | N            |                                         |
| **updated_at**    | Дата и время последнего изменения            | TIMESTAMPTZ    | N            | DEFAULT CURRENT_TIMESTAMPTZ             |

---

## 3. Таблица `user_color_history` (История смены цветов)


### Индексы
* `id` — Первичный ключ (PK)
* `user_id` — Внешний ключ (FK)
* `changed_at` — Индекс для быстрой сортировки истории по времени

### Структура

| **Атрибут**    | **Описание**                            | **Тип данных** | **Nullable** | **Ограничения / Значение по умолчанию** |
| :------------- | :-------------------------------------- | :------------- | :----------- | :-------------------------------------- |
| **id**         | Уникальный идентификатор записи истории | UUID           | N            | Primary Key                             |
| **user_id**    | Идентификатор пользователя              | UUID           | N            | FK → `users.id` (ON DELETE CASCADE)     |
| **color**      | Цвет фона, который был установлен       | VARCHAR(11)    | N            |                                         |
| **changed_at** | Дата и время смены цвета                | TIMESTAMPTZ    | N            | DEFAULT CURRENT_TIMESTAMPTZ             |
